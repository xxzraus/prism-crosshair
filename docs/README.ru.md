# PRISM — документация

Лёгкий оверлей-прицел для Windows с редактором формы, цвета и поведения.

[English version](README.md)

## Возможности

- 8 форм прицела: перекрестие, точка, кольцо, Т-образный, икс, шеврон, скобки, гибрид.
- 48 цветов, HEX, второй цвет и градиент.
- Контур, свечение, скруглённые концы, поворот, масштаб и анимация.
- 12 готовых пресетов и собственные профили.
- Живой просмотр на экране во время настройки.
- Оверлей поверх окон и клик сквозь него.
- Глобальные горячие клавиши с переназначением.
- 6 тем, экономный режим, трей, автозапуск и монитор нагрузки.
- Русский и английский интерфейс.

## Запуск

```text
Portable\Prism.exe
```

Или запустить установщик `Installer\PRISM-Setup-1.1.0.exe`.

Прицел закрепляется в центре выбранного дисплея. Редактор открывается из трея. Сверни студию в трей — оверлей останется поверх игры.

## Горячие клавиши

| Действие | По умолчанию |
|---|---|
| Показать / скрыть прицел | `F8` |
| Следующий прицел | `F9` |
| Открыть редактор | `F10` |
| Аварийно скрыть всё в трей | `F12` |

## Язык

PRISM запускается на английском. Открой **Settings → Language** и выбери **Русский**. Язык сохраняется и применяется сразу.

## Данные

- Настройки: `%APPDATA%\PrismCrosshair\settings.json`
- Лог: `%APPDATA%\PrismCrosshair\prism.log`

## Ограничения

- Эксклюзивный полноэкранный режим может скрывать сторонние оверлеи. Используй безрамочное окно.
- Проверяй правила игры и античита. PRISM не читает память игры, не внедряется в процесс и не меняет её файлы.

