# PRISM 1.1 — Portable

1. Run `Prism.exe`.
2. The studio opens and the crosshair is pinned at the center of the screen.
3. Minimize the studio to the tray — the crosshair stays above the game.

Start directly in the tray:

```text
Prism.exe --minimized
```

Hotkeys:

- `F8` — show / hide the crosshair
- `F9` — next preset
- `F10` — open the editor
- `F12` — panic hide (overlay and studio to tray)

Settings: `%APPDATA%\PrismCrosshair\settings.json`

The UI starts in English. Switch to Russian in **Settings → Language**.

In exclusive fullscreen mode Windows may hide third-party overlays — use borderless windowed mode.

Check the rules of your game and anti-cheat before using overlays.
